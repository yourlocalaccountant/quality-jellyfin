# quality-jellyfin

Neat little command designed to change the text from the quality section from just bitrate to for example, 1080p (5 Mbps).


Install Commands

curl -fsSL https://raw.githubusercontent.com/yourlocalaccountant/quality-jellyfin/main/install.sh | sudo bash

Docker Install

docker exec -it jellyfin bash -c "$(curl -fsSL https://raw.githubusercontent.com/yourlocalaccountant/quality-jellyfin/main/install.sh)"
